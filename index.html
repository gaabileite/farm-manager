Sobre o projeto

Trabalho prático da disciplina CIN0135 — Estruturas de Dados Orientadas a Objetos (CIn/UFPE, 2026.2).

O problema

Stardew Valley tem dezenas de moradores, dezenas de tipos de plantações, animais, construções e missões. Durante a partida, é difícil lembrar preços, estações de cultivo, presentes favoritos e o que já existe na fazenda.

A solução

O Farmpedia reúne o catálogo do jogo em um banco somente leitura e permite que o jogador registre, consulte, atualize e remova os dados da própria fazenda em um segundo banco.

Os 5 livros do Farmpedia

O sistema é dividido em quatro livros de consulta (catálogo) e um livro de gerenciamento (a fazenda do jogador).

Catálogo

Livro 1 — Crops

  • Estação e dias até a colheita
  • Preço de venda por qualidade
  • Preço das sementes e itens artesanais
Catálogo

Livro 2 — Villagers

  • Presentes amados, gostados, neutros e odiados
  • Níveis de amizade (corações)
  • Rotinas e relacionamento
Catálogo

Livro 3 — Animals

  • Tipos de animais e seus produtos
  • Dias até a fase adulta
  • Preço de compra e derivados
Catálogo

Livro 4 — Buildings

  • Materiais e custos
  • Capacidade para animais
  • Tamanho no grid
CRUD do jogador

Livro 5 — My Farm

  • Create: adiciona animais, construções e relacionamentos
  • Read: mostra o resumo completo da fazenda
  • Update: atualiza afeição e amizade
  • Delete: remove registros antigos

Exemplo de código real do projeto

// DataType.h — Classe base do catálogo do jogo
class DataType {
protected:
    std::string name; // protegido para ser herdado
public:
    DataType(const std::string& name); // referência constante
    virtual ~DataType() = default;     // destrutor virtual para polimorfismo
    std::string getName() const;      // encapsulamento (getter)
};

// Crop.h — Herança de DataType
class Crop : public DataType {
private:
    std::string season;
    int daysToHarvest;
public:
    Crop(const std::string& name, const std::string& season, int days)
        : DataType(name), season(season), daysToHarvest(days) {}
};

// MyFarm.h — Composição e ponteiro para SQLite3
class MyFarm {
private:
    std::string farmName;
    std::vector<MyAnimal> myAnimals; // composição
public:
    void loadFarmData(sqlite3* db);   // uso de ponteiro do driver C
};

Como compilar e executar

O sqlite3.c é C puro e precisa ser compilado com gcc antes do código C++17. Execute sempre da raiz do projeto, para que os caminhos dos bancos funcionem.

Linux / macOS

gcc -c external/sqlite3.c -o sqlite3.o
g++ -std=c++17 src/main.cpp src/database.cpp \
  src/filters.cpp src/menu.cpp src/definitions.cpp \
  sqlite3.o -o farm_manager
./farm_manager

Windows (PowerShell)

gcc -c external/sqlite3.c -o sqlite3.o
g++ -std=c++17 src/main.cpp src/database.cpp `
  src/filters.cpp src/menu.cpp src/definitions.cpp `
  sqlite3.o -o farm_manager.exe
.\farm_manager.exe

Sobre o Projeto

O Farm Manager é uma aplicação desenvolvida em C++ com suporte a banco de dados SQLite para gerenciar dados do catálogo do jogo e acompanhar o progresso da fazenda do jogador. Na interface gráfica, cada uma das classes do sistema é acessada visualmente como um livro.

Arquitetura e Conceitos de POO

O sistema foi modelado utilizando conceitos fundamentais de Orientação a Objetos:

  • Herança: A classe DataType atua como classe mãe, fornecendo a estrutura base para as subclasse de referência do jogo (Crop, Villager, Animal e Building).
  • Composição: A fazenda do jogador é representada pela classe MyFarm de forma independente, agrupando as coleções próprias do jogador (myAnimals, myBuildings e myRelationships).

Modelagem das Classes

Catálogo de Referência (Herança): DataType ├─ Crop ├─ Villager ├─ Animal └─ Building Fazenda do Jogador (Composição): MyFarm ├─ myAnimals (vector<MyAnimal>) ├─ myBuildings (vector<MyBuilding>) └─ myRelationships (vector<MyRelationship>)

Funcionalidades e Operações CRUD

  • Consulta (Read): Leitura das informações estáticas do catálogo do jogo e visualização dos dados da fazenda ativa.
  • Cadastro (Create): Registro de novos animais, construções e relacionamentos na fazenda.
  • Atualização (Update): Alteração dos níveis de amizade, evolução de edifícios e atualização dos dados salvos no SQLite.
  • Exclusão (Delete): Remoção de registros da fazenda do jogador.

Como Compilar e Executar

Como o arquivo sqlite3.c é escrito em C, ele deve ser compilado separadamente usando gcc antes do código em C++[cite: 5]. Atenção: Execute os comandos sempre a partir da raiz do projeto, pois os caminhos do banco de dados são relativos.

Linux / macOS

gcc -c external/sqlite3.c -o sqlite3.o
g++ -std=c++17 src/main.cpp src/database.cpp src/filters.cpp src/menu.cpp src/definitions.cpp sqlite3.o -o farm_manager
./farm_manager

Windows (PowerShell)

gcc -c external/sqlite3.c -o sqlite3.o
g++ -std=c++17 src/main.cpp src/database.cpp src/filters.cpp src/menu.cpp src/definitions.cpp sqlite3.o -o farm_manager.exe
.\farm_manager.exe
